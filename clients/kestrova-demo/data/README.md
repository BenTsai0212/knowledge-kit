示範素材：

- **權限（等級）**：霧行分三層，公司簡介（公開）只提到新產品開發中，規格書（內部）有規格，`production-plan-2027-ja`（機密）有產量與成本；業務也分三層，保固（公開）、價目表（內部）、Q3 業績（機密）。
- **專案**：霧行的文件（`mistwalk-spec-zh`、`mistwalk-trial-ja`）只有專案成員看得到；港灣標案（`harborline-bid-en`）一般員工的等級夠，但不是成員，所以看不到。
- **比文件更機密的段落**：`harborline-bid-en-03`（投標金額與毛利）。
- **跨語言**：請假規定只在繁中、差旅只在英文、工安只在日文；示範情境的預設問題每題都有三種語言的文字，答案段落只在一種語言。
- **越權測試**：`salary-adjustment-2026-zh` 是主管看得到、一般員工完全看不到的繁中文件。
