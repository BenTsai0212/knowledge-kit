# 凱翠瓦感測資料集

凱翠瓦感測（Kestrova Sensing／ケストロヴァ・センシング）的**虛構**資料：文件、段落、實體與關係。所有公司、人物、產品、專案與金額都是虛構的（Issue #175）。

- 格式與檢查：[docs/dataset.md](../../../docs/dataset.md)
- 不要放入真實客戶資料（AGENTS.md 第 5 節）

## 內容

虛構的工業用環境感測器製造商，三個據點各用一種語言寫文件：台灣總部（繁中）、美國業務子公司（英文）、日本工廠（日文）。**同一個事實只寫在一種語言**，以語意向量（`multilingual-e5-small`）驗收跨語言檢索。

文件在檢查點 1 確認後填入。
